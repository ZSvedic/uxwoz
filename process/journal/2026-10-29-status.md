# 2026-10-29: status before a new session

UX Woz works end to end on a laptop: a prompt makes a screen, clicks make more screens, and every
screen sits on a canvas with arrows showing which click made it. This entry records what changed
since the [first MVP](2026-10-23-mvp.md) and what is open.

## What changed since the MVP

- **Shared places.** Each request lists the screens that already exist, and the model links to them
  by exact prompt, or to the first screen with `home`. Before, every "Back to menu" made a new menu.
- **Mockup theme by default.** Black and white, handwriting font, wobbly borders; a grayscale
  filter turns the model's own colours grey. Plain Pico is "Clean".
- **Canvas.** Cards with labelled arrows (first click places a screen; later clicks are dashed back
  arrows), focus on the current card with its parent in view, Fit all, pan and zoom.
- **Whole screens.** A card is as tall as its screen; scrolling moves the canvas. vh units become
  pixels of an 800 px window, so "full-screen" designs cannot stretch a card without end.
- **Examples.** The "Schrodinger 3000 cat app" prompt is an example button.
- **Clean-up.** AGENTS.md now has a code map and a do-not-read list; stale text copied from
  another project is gone; `tsc` refuses unused locals.

## Lessons

- The cache stores links inside screens, so a prompt fix does not change screens made before it.
  Clearing `temp/screen-cache.json` was the fix; a prompt version in the cache key is an option.
- JavaScript inside our frame script lives in a TypeScript template string: regex backslashes must
  be doubled (`\\s`), or they vanish. Two bugs came from this; tests now run the helpers.
- Bun's `--hot` server cannot add a new frontend file: restart it.
- The browser test tool cannot click inside a zoomed iframe; set the zoom to 100% to test clicks.
