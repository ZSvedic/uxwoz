the ceremony shrank to one brief, one build, one critic round and one merge. Deleting files
changed little on its own (the builders never opened `benchmarks/`); the split mattered because
sharing, voice and export each touched `toolbar.ts` and `drawer.ts` in a few lines and merged
with two trivial conflicts.

## The critics earned their keep

Three critic rounds found 22 defects; the builders had tested and reported green each time.

- **Export** (6): a link inside a clickable element did nothing, the current tab was not marked,
  Back used the browser's history, accents fell out of the file name, two wording errors.
- **Sharing** (8, three confirmed by request against a running server): an edit link could change
  another mockup through `?app=`, delete one with an array key, and the server fetched its own
  pages from whatever host the visitor named. Plus a flood of trips pushing out real ones and a
  request on every drawer open.
- **Voice** (8): a request ending in *stop listening* was dropped, a countdown could stall
  forever, typed text was overwritten, *aborted* errors restarted without end.

## Known gaps

- Sharing links need a host on the internet to be useful. The owner gate (`UXWOZ_OWNER`) is a
  cookie with the secret, enough for a handful of reviewers, not for the public.
- A share link can be made only after the first screen is picked.
- A thumb given before the visitor typed a name shows as *Someone*.
- Start over and Delete drop the mockup's links and feedback (the confirm text says so).
- The design variants load one Google Font each; a chosen one gets its font copied into
  `themes/`.
- Voice recognition is set to English (`en-US`). Chrome sends the audio to Google.
- Production mode (`bun run start`) of `/s/<token>` was checked by the critic, not by me.
